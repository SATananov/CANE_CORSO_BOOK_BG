## Mandatory distinctions locked

The terminology authority explicitly separates:

1. established historical fact;
2. historical hypothesis;
3. interpretation;
4. Dott. Flavio Bruno’s personal position;
5. Stefano De Tanini’s editorial narrative.

It also forbids converting:

- functional similarity into genealogy;
- morphological similarity into kinship;
- a historical name into a standardized modern breed;
- an illustrative reconstruction into an authentic historical image;
- testimony into proof;
- absence of evidence into a plausible invented narrative.

## Principal consistency risks

| Risk | Locked control |
|---|---|
| `Cane Corso` capitalization and inconsistent Bulgarian spelling | Use **Кане Корсо** in Bulgarian prose; retain Italian only in original titles/quotations. |
| Treating `cane Pugnax`, Pugnax, or Bellator as proven modern breed ancestors | Retain historical/Latin forms and preserve their interpretive status. |
| Mixing `molosso` and `molossoide` | Use **молос** and **молосоид** as distinct terms. |
| Translating `transumanza` too narrowly or romantically | Use **сезонно придвижване на стадата (трансхуманс)** at first occurrence. |
| Confusing `gregge`, `mandria`, `bestiame`, and `bovini` | Locked respectively by livestock scope: sheep/small livestock, large livestock herd, livestock, cattle. |
| Rendering `presa` uniformly | Use **захват** for action/mechanics and **задържане** for functional outcome. |
| Confusing courage, aggression, character, and temperament | Separate locked forms: **смелост**, **агресивност**, **характер**, **темперамент**. |
| Equating functional continuity with genealogical continuity | Use **функционална приемственост** versus **генеалогична приемственост**. |
| Losing Bruno/De Tanini attribution | Mandatory named attribution patterns are included. |
| Treating hypotheses/maps as documented migration or descent | Hypothesis markers are mandatory in text and graphics. |
| Translating bibliographic titles as if Bulgarian editions existed | Preserve original published titles; optional Bulgarian gloss only in square brackets. |
| Inconsistent diagram labels | A locked label set is provided for methodology, atlas, anatomical, and functional graphics. |
| Confusing documentary materials with illustrative reconstructions | Separate mandatory source-status labels are locked. |
| Using „куче тип Кане Корсо“ as normal prose | Prefer **куче от типа Кане Корсо**; shorten only for strict graphic/table constraints. |
| Using a single register for `accoppiamento` | Prefer **чифтосване** in normal prose; reserve **съешаване** for technical/zootechnical contexts. |
| Weakening or overclaiming `La funzione fa il tipo` | Use **„Функцията формира типа“** and retain its status as Bruno’s functional thesis. |
