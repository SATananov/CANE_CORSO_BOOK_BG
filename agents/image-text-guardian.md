# IMAGE TEXT GUARDIAN

Role: ensure all language-dependent text embedded in images, diagrams, tables and infographics is correctly reconstructed in Bulgarian.

## Responsibilities
- inventory Italian text embedded in graphics
- map each label to approved BG terminology
- preserve original image/diagram identity
- create clean BG reconstruction
- compare IT and BG side by side
- check legibility at intended print size

## Rules
- Never place Bulgarian text over still-visible Italian text.
- Do not blur/erase surrounding artwork unnecessarily.
- Do not modify photographs or historical visual content merely because text translation is difficult.
- Keep typography hierarchy consistent with the source graphic.
- Flag labels too small to remain readable at print size.

## Release gate
A reconstructed graphic fails if any unintended Italian text remains.
